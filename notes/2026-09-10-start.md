# Initial exploratory protocol — 10 September 2026

This is an interface/acquisition-evidence diagnostic, not a prospective test of parameter acquisition or a replication of a published algorithm. No paid endpoints are used.

## Task and scope

An unfamiliar two-tool router requires a mode-dependent string transformation and a priority-dependent suffix. A deterministic oracle supplies six checked successful interactions. This is researcher-generated supervision, not autonomous discovery. The acquisition examples cover amber/normal, blue/normal and blue/urgent; amber/urgent is a withheld factor combination. Two new strings are used across all four conditions (eight development inputs). All answers differ from acquisition answers. This tests composition and a string operation, but remains a narrow synthetic task.

The Docker Qwen3-4B Q4_K_M pilot compares no evidence, all six examples, and a researcher-written correct rule. The rule is an oracle diagnostic, **not** an evidence-derived learned lesson. The missing fourth combination is not uniquely determined by six examples without an inductive assumption. Consequently, failure on it does not establish a general learning inability.

Use greedy decoding, 96 output tokens, no retries, fresh single-turn requests. Strip only a completed reasoning block and surrounding whitespace; otherwise require the exact oracle tool call. Calls are checked against the simulator's deterministic accepted-call contract, not executed against an external service. Rotate branch order by case. Save complete requests, responses, usage, elapsed time, runtime/model identity, design and source snapshot. Ten-minute request-start budget; 90-second individual timeout. There is no prospective holdout yet; these inputs are development material.

## Completed pilot results

All 24 calls completed without request errors or output-limit termination. Exact-call success: no evidence **0/8**, examples **4/8**, oracle lesson **1/8**. Examples succeeded on all blue cases and failed all amber cases by leaving the string unreversed. The oracle lesson also failed all reversal cases, and often misplaced or omitted suffixes. These eight highly related inputs are not eight independent demonstrations of broad transfer. No uncertainty interval or acquisition claim is warranted.

The correct-procedure diagnostic does not establish execution competence in this interface. Therefore this task/prompt is **not ready for a parameter-storage comparison**. Next, audit the actual tokenizer/chat template and test a clearer interface or simpler argument transformation as a separately identified development revision. Do not tune against a future prospective evaluation set. No adapter was trained in this run.

Docker responses report prefix-cache hits, archived in each response. Raw elapsed times include first-call startup and unequal cache reuse; they must not be interpreted as uncached inference costs or evidence of amortization. The summary records token counts and wall time separately. Researcher time for constructing the protocol/lesson was not instrumented, and no total acquisition cost is claimed.
