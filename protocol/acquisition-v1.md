# Acquisition v1 — frozen before evaluating new inputs

11 September 2026. This is a bounded prospective evaluation of a developed synthetic task, not a replication or claim of novel procedural memory. Earlier pilots are development only.

Task: retain the original uppercase router interface. Twelve oracle-checked demonstrations use cat, fern, oak, reed crossed with amber/normal, blue/normal, blue/urgent. Amber/urgent is withheld. The intended separable rule is an inductive assumption, not uniquely implied by finite demonstrations. Explicit rule is a privileged diagnostic. No autonomous exploration or environment interaction costs are claimed; oracle emits accepted calls under a deterministic contract.

Model: existing local Qwen3-4B-Instruct-2507 bf16 files, identified by prior native-run hashes, pinned MLX-LM dependency. Same native runtime and adapter-wrapped base in every branch. One seed (17), last eight transformer blocks, query/value projection LoRA, rank 8, scale 2, dropout 0; AdamW lr 0.0005, weight decay 0. Batch size one, 8 shuffled epochs over 12 demonstrations = 96 steps. Only assistant answer plus EOS gets loss. No checkpoint selection, target augmentation, rule-in-training-prompt, or test-driven changes. Save final adapter and exact training token sequences. Verify base invariance, exact adapter resets and restored logits. Twenty-minute cooperative total budget, 24 GB peak MLX limit; stop on failure. No sweep to obtain a win.

Branches: (1) no acquisition; (2) all 12 checked examples in context; (3) one generated lesson in context; (4) supplied original correct rule diagnostic; (5) final adapter with no examples/lesson/rule. Generate lesson once before training with base model, greedy max 256 tokens, request <=100 words, from examples only. Retain even if malformed or inaccurate; no editorial repair. All answer calls greedy max 96 tokens, exact-call scoring, no retries. Also report training recall separately (12 prompts, adapter only).

Prospective evaluation generated after this file is frozen: 16 new lowercase strings of lengths 4, 6, 8, 10 from Python Random(20260911), using ASCII lowercase letters, four strings per length, excluding all prior development/acquisition strings. All four condition combinations produce 64 paired tasks, including 16 withheld-combination tasks. These random identifiers extend beyond ordinary training words; report transformation length strata and seen vs withheld combinations. No lexical contamination claim about pretraining. Evaluation is run only after the final checkpoint is fixed; no subsequent fitting.

Repeat workload: two passes through the same 64 tasks per branch, 128 measured uses. Repetitions are not independent test cases. Rotate five branches within each task, switching between initial/final adapters in memory, fresh generation caches every call. Save all prompts, token IDs, raw outputs, latency and verification cost. Include switching time separately. Report pass-one accuracy and pass-two repeat agreement. Acquisition construction, lesson generation, train tokens/steps/time, preparation, model load/hash overhead and memory separate from use costs. No energy/dollar estimate; researcher labor unmetered. Finite observed reuse and any linear break-even projection must be labeled separately. Do not declare a cost win if useful performance is lower; even a projection at equal observed accuracy is exploratory with one timing run.

Implementation failure permits a documented code repair and separately preserved failed attempt, not a protocol/hyperparameter change. No later-learning/correction extension in this campaign. Final local note includes negative or inconclusive results and reproduction instructions.
